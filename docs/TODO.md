# Publication follow-ups

The repository is source-ready. These distribution items require project-owner
credentials or branding decisions and are deliberately not automated:

- Add a final app icon asset and product screenshots.
- Install a Developer ID Application certificate and create the
  `notarytool` Keychain profile described in `README.md`.
- Rename the GitHub repository if the current remote name is unintended.
- Decide whether to rewrite pre-publication Git history to remove old compiled
  artifacts and author metadata; do not rewrite shared history casually.
- Enable branch protection and required CI checks after the first push.
